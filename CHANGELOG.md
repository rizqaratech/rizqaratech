
---

## Versioning Guide

Use simple semantic versioning:

```text
MAJOR.MINOR.PATCH
```

Example:

- `1.0.0` = first stable version
- `1.1.0` = new feature added
- `1.1.1` = small bug fix
- `2.0.0` = major change or breaking update
